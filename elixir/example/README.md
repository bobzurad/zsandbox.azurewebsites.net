# Example

This project is a "Hello World" Elixir app, and was  generated with `mix new example`. 

## Prerequisites and Dev Setup

This proect requires Erlang and Elixir. This project contains a `.tool-versions` file, so if you have [asdf](https://asdf-vm.com) installed, you can use `asdf install erlang` and `asdf install elixir` to ensure that you're using the proper version of Elixir.

## Building

`mix.exs` is configured to use escript to run the app. Run `mix escript.build` to generate the script to execute.
